# Sales Forecast Project

This project provides a starter structure for building and evaluating a sales forecasting pipeline.

## Structure
- data/raw: original source data
- data/processed: cleaned and feature-engineered data
- notebooks: analysis and modeling notebooks
- src: reusable Python modules for preprocessing, feature engineering, training, forecasting, and evaluation
- models: trained model artifacts
- reports: charts and summaries
- dashboard: BI file placeholder

## Getting started
1. Install dependencies: `pip install -r requirements.txt`
2. Place historical sales data in `data/raw/`
3. Use the notebooks in order to explore and train the forecasting model
4. Save trained models in `models/`
